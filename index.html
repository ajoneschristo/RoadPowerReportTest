⚡ Road Power Report Settings
Shared with ePass Viewer — only the party list is written back
JSON file inside the epass-db repo holding the day-wise history. Keep the test app on a different filename from production.
The first pair covers the months you pin with ☆ Show in Saved days; the second pair covers the month on screen. Each report answers separately depending on whether its day-by-day switch is on, so a wide day-by-day view can drop the summary columns while the compact view keeps them.
Party Code Party Name ⛓ Power R1 R2
Power — treated as power sector, its figures are written to the history file. R1 — appears as a row in Road Despatch to Power Sector. R2 — gets a block in the Customer report. Ticking R1 or R2 ticks Power automatically. One row per party code, so a party with several codes needs each code ticked.
Codes: comma-separated colliery codes (e.g. 5046 or 5046,5075,5077). Leave In total ticked for an ordinary colliery column. Untick it for a roll-up column such as “Talcher Total”, which already contains other columns and would otherwise be counted twice. At least one column must stay ticked, or the Total has nothing to add.
